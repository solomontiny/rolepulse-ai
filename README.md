# RolePulse AI

RolePulse AI is a future-of-work prototype that helps track how AI is changing jobs across industries. It highlights AI exposure, automation levels, market direction, and role resilience through a clean dashboard experience.

## Features

- Job dashboard with filters and search
- AI exposure scoring
- Automation level tracking
- Market direction insights
- Job detail pages
- Skills to stay relevant
- Recommended AI tools
- Career outlook

## Tech Stack

- React
- TypeScript
- Vite
- Tailwind CSS

## Run Locally

    npm install
    npm run dev

## Status

Prototype using sample data for future-of-work exploration.
